## What this repository is

Craig Thacker's personal configuration repo, `craigthackerx/craigthackerx-personal`. Today it
holds his World of Warcraft UI for WoW Forever and retail: an EllesmereUI profile, a Blizzard
Edit Mode layout, keybinds, and the Python tools that generate and verify them. The working
branch is `dev`.

In September 2026 the repository was cut back to that. Everything older (DigitalOcean DNS
Terraform and its workflows, a TeamSpeak stack, setup scripts, IDE settings, ElvUI, WeakAuras
and other addon exports) is preserved in the `legacy` tag.

## Rules

These are standing rules. Follow them without being reminded.

1. **Commits are Craig's.** Use the git identity and `gh` CLI already configured on this
   machine. Commits and tags are GPG signed automatically by the existing git config. Do not
   set up other credentials, tokens or SSH keys.
2. **No commit trailers or attribution, ever.** No `Co-Authored-By`, no `Signed-off-by`, no
   "Generated with" lines, no tool or AI attribution, in commit messages or pull request
   bodies. Write commit messages in English with a short imperative subject, wrapped at 72
   characters, and a body only when the change needs explaining.
3. **Branches and history.** Work on `dev`. Never push to `main` (untouched since 2022), force
   push, rewrite history, or move or delete tags, `legacy` included. Push `dev` when a piece
   of work is complete. Open a pull request only if Craig asks.
4. **Docs style.** British English (colour, organise, behaviour, licence as a noun). No en or
   em dashes anywhere in docs, comments or commit messages: use commas, colons, brackets or
   separate sentences. `just lint` checks files. Check commit messages yourself.
5. **Profile and layout strings are opaque data.** Never hand edit, reformat or rewrap them.
   Each stays on a single line with no trailing newline. Change them only with the tools,
   then run `just verify`.
6. **Generated files are never edited directly.** `retail.txt` and `Craigtho-retail.txt` are
   rebuilt from their Forever sources with `just regen`. Retail only EllesmereUI settings
   (Mythic+ Tools, Friends, Dragon Riding) live in `wow/tools/eui_make_retail.py`.
7. **Never commit EllesmereUI full account exports** (`eui_decode.py` reports
   `type=fullaccount`). They carry character gold, bag contents and click cast bindings, and
   this repository is public. Commit profile exports only (`type=full`). Never commit decoded
   `.lua` or `.json` output, `wow/tools/.deps/` or `wow/tools/.venv/`.
8. **Do not guess game facts.** WoW Forever is new and still changing. If docs need a fact you
   cannot verify, leave it out or ask Craig.
9. **Keep the scope.** Do not bring back anything from the `legacy` tag unless Craig asks.

## Validating changes

Set up once:

```bash
just setup    # wow/tools/.venv with lupa, plus the pinned Lua sources in wow/tools/.deps
```

Before every commit:

```bash
just lint     # ruff, shellcheck, LF, executable bits, dashes, secret material
just verify   # export checks, then regenerate both retail files and compare byte for byte
```

After changing a Forever string, run `just regen` and commit the Forever and retail files
together. CI (`.github/workflows/ci.yml`) runs the same scripts plus a gitleaks scan of the
full history, on every push to `dev` and on pull requests. `just ci` runs all of it locally if
gitleaks is on PATH.

## Things already learned the hard way

- **A dash check must honour `.gitignore`.** A naive walk of the working tree scans
  `wow/tools/.deps/`, whose EllesmereUI sources are full of en dashes, and reports hundreds of
  false positives. `lint.sh` uses `git grep --untracked`, which skips ignored files, and
  matches the UTF-8 bytes so the result does not depend on the locale.
- **`git add --renormalize` fixes the index, not the working copy.** A file can be committed
  as LF and still be CRLF on disk. Delete it and `git checkout -- <file>` to rewrite it.
- **The checkout is on `/mnt/c` (drvfs), where `core.filemode` is false.** `chmod` does
  nothing git can see. Set the executable bit with `git update-index --chmod=+x <file>`. The
  lint checks the bit in the index.
- **Ubuntu's system Python refuses `pip install`** (PEP 668). Use the venv from `just setup`,
  or point `PYTHON` at another interpreter that has lupa.
- **The tools lift code out of `EllesmereUI_Profiles.lua` by text markers.** An EllesmereUI
  update can move them. `wow/tools/README.md` lists the markers and the bump procedure.
- **Retail refuses Forever's Edit Mode layout versions.** The handover assumed retail would read
  version 3, the format Forever wrote before version 4, and retail 12.1 refused that layout.
  The converter now writes version 2, the version retail itself exports, and
  `check_exports.py` enforces it. Confirm game facts like this against a native export
  before trusting them.
- **`eui_decode.py` writes next to its input by default.** Pass `--out` pointing at a
  temporary folder, so decoded output never lands in the tree.
